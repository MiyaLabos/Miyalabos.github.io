# 参照資料と収録範囲

確認日：2026年9月8日

## 対象

東京書籍『NEW HORIZON English Course』令和7年度版（2026年度使用）の中学1〜3年向けです。

| 学年 | 収録範囲 | 語数 |
| --- | --- | ---: |
| 中学1年 | 第1〜10単元と関連教材 | 150 |
| 中学2年 | 第1〜7単元と関連教材 | 105 |
| 中学3年 | 第1〜6単元と関連教材 | 90 |

教科書全体の主要単元にまたがる345語を選んでいます。教科書に掲載されるすべての語・熟語・活用形を網羅する単語集ではありません。各単元の後にある読み物・活動・音と文字の教材も、参照先の単元区分に含むため、画面には「第○単元・関連教材」と表示します。学期や授業の進度による絞り込みはありません。

## 掲載語の照合

- [東京書籍・令和7年度本教科書掲載語彙データの案内](https://ten.tokyo-shoseki.co.jp/text/chu/eigo/download/)
- [公式語彙表（エクセル）](https://ten.tokyo-shoseki.co.jp/text/chu/eigo/download/documents/eigo_19goidata.xlsx)

公式語彙表の「本文Word List 単語一覧」「本文題材語一覧」「本文Word List外の語」と345語の綴りを照合し、すべて掲載されていることを確認しました。この公式語彙表には単語ごとの学年・単元・日本語訳は含まれません。

- [英語漬け・中学1年の単元一覧](https://www.eigo-duke.com/tango/textindexchu1nh.html)

問題データの各項目に、照合した単元ページのURLを保存しています。単語と学年・単元の対応という情報を参照しており、参照サイトの問題文・選択肢・解説・プログラムは使用していません。教科書の本文・画像・音声もアプリには収録していません。

## 日本語訳と誤答候補

日本語訳と3つの誤答候補は、このアプリ用に作成しています。日本語訳は代表的な語義に絞っており、教科書巻末の訳語を一字一句再現したものではありません。品詞を表示し、多義語の別の意味が正解候補と競合しないようにしています。

誤答候補は、原則として同じ学年・同じ品詞の別の語の意味から事前に選びます。同義語、親・父など意味が包含される語、似た意味の語の組み合わせは除外します。代名詞・前置詞など候補数が足りない場合には、あらかじめ用意した日本語候補を使用します。ブラウザでは保存済みの4択を並べ替えるだけで、新しい誤答は生成しません。

- [中学1年・令和7年度から8年度への訂正](https://ten.tokyo-shoseki.co.jp/text-information/chu/english-r7/r7-8_j_english_1.pdf)
- [中学2年・令和7年度から8年度への訂正](https://ten.tokyo-shoseki.co.jp/text-information/chu/english-r7/r7-8_j_english_2.pdf)
- [中学3年・令和7年度から8年度への訂正](https://ten.tokyo-shoseki.co.jp/text-information/chu/english-r7/r7-8_j_english_3.pdf)

各学年の訂正資料を確認しました。収録語に直接関係する「breed」は訂正後の「繁殖させる」を採用しています。「research」の発音記号は、このアプリでは表示しません。本文・図版・発音・熟語の訂正のうち、収録対象外の項目は問題データに影響しません。
