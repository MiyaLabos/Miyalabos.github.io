# 英単語の時間

iPadのブラウザで使う、中学生向け英単語4択テストです。東京書籍『NEW HORIZON English Course』令和7年度版（2026年度使用）の掲載語を使います。

## 使える機能

- 中学1〜3年の選択
- 選んだ学年から重複なしで10問をランダム出題
- 英単語に対する日本語の意味を4択で回答
- 回答直後の正誤・正解表示と、手動での次問への移動
- 10点満点・正答率・全問の振り返り
- 同じ学年での再挑戦、学年変更、途中終了の確認
- iPadの縦・横画面や小さい画面に合わせた表示
- キーボード操作、拡大表示、読み上げに対応するラベル
- 通信失敗・不正なデータ・読み込み時間超過の案内と再試行

初期収録数は中学1年150語、中学2年105語、中学3年90語の合計345語です。全23主要単元と関連教材から選んでいます。教科書の全掲載語を網羅してはいません。詳しい照合方法・資料は [参照資料と収録範囲](data/sources.md) を参照してください。

## 起動

Node.js 20以降で、追加のパッケージをインストールせずに実行できます。

```sh
npm start
```

パソコンでは `http://localhost:4173` を開きます。iPadでは同じネットワークに接続し、パソコンのローカルIPアドレスを使った `http://パソコンのIPアドレス:4173` をSafariで開きます。ファイアウォールで接続が許可されている必要があります。

HTMLをファイルとして直接開くと、ブラウザの制約で問題データを読み込めません。確認用サーバーまたは公開先のURLから開いてください。

## 静的サイトとして配置

HTML・CSS・JavaScript・JSONのみで動作します。バックエンド、外部APIキー、ビルド用ライブラリは不要です。

```sh
npm test
npm run build
```

生成された `dist` の内容を、静的サイトの公開先へ配置できます。このリポジトリをGitHub Pagesで公開する場合は、`EnTangoTest` 配下のソースをそのまま配信しても動作します。各ファイルを相対パスで参照しているため、サブディレクトリに配置できます。

## データを変更するとき

- `data/vocabulary.tsv`：学年・単元・英単語・品詞・日本語訳の編集元
- `scripts/prepare-data.mjs`：誤答候補を事前に作成する処理と、類義語の除外設定
- `data/questions.json`：ブラウザが実際に使用する問題と誤答候補
- `quiz.js`：データ検証・抽選・回答・採点
- `app.js`：画面と操作

編集後に次を実行します。

```sh
node scripts/prepare-data.mjs
npm test
npm run build
```

誤答候補の生成はこの準備工程だけで行います。生成結果の日本語・語義・品詞を点検してから使ってください。`questions.json` を直接調整した内容は再生成で上書きされるため、継続的な調整は編集元または生成処理へ反映します。

## 状態管理

問題と選択肢の順番を開始時に確定し、回答はそのテストのメモリ内だけに保持します。回答確定後は変更できません。再読み込みやタブを閉じる操作で状態がリセットされます。氏名・成績の収集、ログイン、保存、時間制限はありません。

## 検証

`npm test` は全学年の収録データ、重複のない10問抽出、4択の正解位置、二重回答防止、古い問題の操作防止、0点・6点・10点の採点、再挑戦の初期化、不正データの検出を確認します。

Chromeの専用一時プロファイルで、1024×768、768×1024、390×844の画面表示とタッチ操作、全学年の10問回答、10点・6点・0点の採点、結果一覧、再挑戦、途中終了とキャンセル、画面回転、再読み込み、通信失敗・不正データからの再試行を確認しています。任意の再検証には `tests/browser-check.mjs` を使用できます。

iPad実機およびSafariエンジンでの検証は未実施です。利用するiPadのSafariで最終確認してください。
